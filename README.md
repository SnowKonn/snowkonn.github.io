# snowkonn.github.io

권순호(SoonHo Kwon)의 소개 페이지와 발간 리포트 목록이다. 한국어 페이지는 `/`, 영어 페이지는 `/en/`에 있다.

Personal profile and publication list of SoonHo Kwon, quant analyst. Korean at `/`, English at `/en/`.

## For AI agents

| Path | Contents |
|---|---|
| `/llms.txt` | Overview and the full report list with titles, dates and links |
| `/llms-full.txt` | The same list plus the Korean summary published with each report |
| `/publications.json` | One structured record per report, with a `schema` entry describing the fields |
| `/reports/` | One PDF and one plain-text extraction per report, named `<date>-<broker>-<id>` |
| `/study/` | Study notes written with AI (PDF). Listed in `/llms.txt`; not peer reviewed |

A report is listed only if the author is named on its first page (PDF text, or OCR of the cover where the byline is set as outlines) or in the author column of the broker's research board. Only sole-author reports are listed. Monthly house compilations, weekly strategy notes, routine daily commentary and co-authored reports are left out. Copyright in each report belongs to the publishing broker; the files are kept as the author's own record of publication.

## Layout

```
data/profile.json        bilingual copy, brokers, topics, repositories
data/curation.json       hand edits per report: English title, topics, role, drop
data/publications.json   the canonical list (generated by tools/curate.py)
data/study.json          the "Study with AI" section: copy and one entry per note in docs/study/
data/stoploss.json       copy (ko/en) of the stop-loss calculator at /stoploss/ and /en/stoploss/
data/vol_universe.json   asset classes offered in the calculator, one Yahoo Finance ticker each
data/vol.json            volatility estimates for them (generated by tools/update_vol.py)
src/                     style.css, site.js; tool.css and stoploss.js for the calculator
tools/collect_reports.py Naver research API -> authored reports (data/raw, not committed)
tools/collect_ibks.py    IBK Securities research board (has an author column) -> all rows
tools/match_ibks.py      IBK board rows by the author <-> Naver listings, by attachment file name
tools/recheck_ibk.py     second-pass full-page OCR of IBK non-hits
tools/ocr.swift          macOS Vision OCR helper (swiftc -O tools/ocr.swift -o data/raw/bin/ocr)
tools/curate.py          raw hits + curation -> data/publications.json
tools/build_site.py      data + src -> docs/ (also cuts the web fonts down to the characters on the page)
tools/auto_update.py     daily job: new sole-author Daishin report -> curate -> build -> commit -> push
tools/update_vol.py      Yahoo Finance daily closes (yfinance) -> data/vol.json; run by hand, then build
docs/                    the published site (GitHub Pages serves this folder)
```

## Update

```bash
python tools/collect_reports.py --floor 2026-10   # re-scan recent months (needs requests, PyMuPDF)
python tools/curate.py                             # then add English titles and topics in data/curation.json
python tools/build_site.py
```

## Automatic update

`tools/auto_update.py` runs daily at 19:30 from launchd (`~/Library/LaunchAgents/com.snowkonn.site-autoupdate.plist`, log in `~/Library/Logs/snowkonn-site-autoupdate.log`). It scans the current and previous month of Naver research for Daishin Securities, keeps a report only if the author is named on its first pages, builds the site, commits and pushes. It stops with a Telegram alert (`~/.openclaw/scripts/notify-ops.sh`) if the working tree is dirty, a step fails, or the push does not show up live.

- A new report that also names another Daishin analyst on its cover is held, not published: `data/curation.json` gets `drop` and `hold` for it. To publish it, delete both and set `"keep": true`.
- The English title and topics of a new report come from `claude -p` (sonnet). If that call fails the page shows the Korean title until you fill `title_en` and `topics` in `data/curation.json`.
- Test: `python tools/auto_update.py --dry-run` (add `--pretend-new <id>` to walk through the publish path with an existing report).
- IBK Securities reports are not scanned any more; the list for 2025-01 to 2026-02 is final.

## Stop-loss calculator

`/stoploss/` (Korean) and `/en/stoploss/` (English) compute the best fixed stop-loss for a scenario table
and a volatility, with the formulas of the study note Part I. Everything runs in the browser; the page
makes no request after it has loaded. `src/stoploss.js` exports the calculation for Node, so it can be
checked against the note:

```bash
node -e 'const c=require("./src/stoploss.js"); console.log(c.best(c.setup([{p:40,R:.4},{p:40,R:.1},{p:20,R:-.35}],.3,1)))'
# kind "stop", a 0.2886 (a stop 25.1% below entry), g 0.0851, none 0.0416
```

The volatility presets are historical values. Refresh them with `python tools/update_vol.py`
(needs `pip install yfinance`), then `python tools/build_site.py`. The daily job does not do this.
